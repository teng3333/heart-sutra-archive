# 曼荼羅背景：クロードコードへの最初の指示

高尾さんへ：下の「貼り付ける指示」を、段階ごとにクロードコードへそのまま貼ってください。一度に一つだけ渡し、合格を出してから次を渡します。

クロードコードへ：このファイルと `requirements.md` を最後まで読んでから動くこと。このリポジトリの `CLAUDE.md`、`AGENTS.md`、`ECOSYSTEM_HANDOFF.md` の作業ルールがすべて適用される。

## このフォルダにあるもの

| ファイル | 中身 |
| --- | --- |
| `requirements.md` | 要件定義書 v3.0。何を作るか、合格条件、未決事項 |
| `mandala-prototype.html` | 試作。単体で動く。見た目と動きの正解 |
| `verify/sim.js` | 試作の通し検査（画面なし）。`node docs/mandala/verify/sim.js demo` と `… track` |
| `CLAUDE_CODE_START.md` | このファイル |

## 守ること（要点）

1. **一つずつ。** いま渡された段階だけをやる。次の段階の作業を先取りしない。
2. **既存を壊さない。** 既存の背景、再生、画像保存、動画保存の見た目と挙動は変えない。`src/js/living-bg.js` は自動生成なので編集しない。
3. **音楽を止めない。** 曼荼羅のために `<audio>` を AudioContext へつながない（携帯で曲が止まる。`requirements.md` 3章）。
4. **移植する。作り直さない。** 試作の描画の数式と動きを変えない。気づいた改善は提案として列挙する。
5. **本番に出さない。** 作業は枝（ブランチ）で行う。main への反映と push は、高尾さんが明示的に許可した時だけ。
6. **報告は証拠つき。** 実行した検証と結果、していない検証とその理由を書く。高尾さんは技術用語に慣れていないので、噛み砕いた日本語で書く。
